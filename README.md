# Chap5 Composite Pattern

This console application demonstrates the Composite design pattern.

## Requirements

- [Visual Studio Code](https://code.visualstudio.com/)
- Any .NET 10 SDK version
- The C# Dev Kit extension for Visual Studio Code

The project targets `net10.0` and does not pin an SDK patch version. Install any .NET 10 SDK available to you.

## Open, build, and run

Open this folder in Visual Studio Code and install the C# Dev Kit extension from the Extensions view. From the integrated terminal, build and run the application:

```sh
dotnet build
dotnet run --project Chap5CompositePattern
```

The application waits for a key press before it exits.
